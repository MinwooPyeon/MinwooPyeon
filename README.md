## 핵심 역량

**01 · 임베디드 시스템 개발**

C/C++ 기반 펌웨어 개발과 Raspberry Pi, ESP32 등 실제 하드웨어 플랫폼 활용 역량을 보유합니다. I2C·MQTT 통신 디버깅 및 DMA 기반 모터 제어를 직접 구현했습니다.

**02 · ROS2 자율주행 로보틱스**

ROS2 기반 AMR 자율주행 로봇을 개발하며 IMU 센서 처리, 상보필터 구현, I2C 통신 지연 원인 규명을 수행했습니다. 직진 성공률을 약 30% 향상시켰습니다.

**03 · 데이터 기반 AI 모델링**

Python과 LSTM 모델을 활용한 시계열 예측 프로젝트에서 데이터 전처리 개선으로 모델 오차를 약 40% 감소시켰습니다. Agile·Jira 기반 팀 협업에도 익숙합니다.
